# Baião de Ferrugem — prévias PSG

Primeira versão da nova direção sonora de Plaguefall: inspiração nordestina e textura industrial, sintetizadas nos quatro canais PSG do Mega Drive.

- [Ouvir a versão calma](baiao-calmo.mp3) / [WAV](baiao-calmo.wav).
- [Ouvir a versão de combate](baiao-combate.mp3) / [WAV](baiao-combate.wav).
- [Trilha anterior](anterior.mp3) / [WAV](anterior.wav).
- [Direção sonora, arquitetura, partitura e reprodução](../../doc/musica.md).
- [Validação e dados das gravações](validation.json).

Os áudios foram gravados diretamente do Genesis Plus GX executando a ROM da bancada. A versão calma usa zero inimigos; a de combate usa quinze e aguarda a estabilização do andamento antes de gravar. Os MP3s foram codificados dos WAVs sem processamento adicional. Os timbres são aproximações no PSG, sem amostras acústicas.
